Sistema Color - instalação piloto
=================================

Na pasta extraída do .zip (pendrive):

  instalar.cmd          Primeira instalação neste PC (modo treino).
  atualizar.cmd         Instala uma versão nova. Os dados são mantidos e
                        um backup é feito antes de qualquer mudança no banco.

Na pasta instalada (%LOCALAPPDATA%\ColorBMS) e no pendrive:

  iniciar.cmd           Inicia o sistema e abre a tela inicial.
  parar.cmd             Para o sistema.
  iniciar-uso-real.cmd  Começa o uso real (dia 1º do mês): guarda os dados
                        de treino em "arquivo" e começa com o sistema vazio.

O sistema inicia sozinho quando o Windows é iniciado. Para abrir, use o
atalho "Sistema Color" na área de trabalho (ou http://127.0.0.1:3210).

Se algo der errado, os registros ficam em
%LOCALAPPDATA%\ColorBMS\data\logs (ou data-treino\logs no modo treino).
